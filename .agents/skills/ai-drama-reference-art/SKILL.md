# AI短剧参考图提示词编写

为AI短剧项目编写GPT Image参考图提示词，涵盖角色参考图（4面板character sheet）和场景参考图两种类型；室内场景按下方专节组织素材，其他场景沿用9宫格多角度流程。

## 参考图类型

### 角色参考图 = 4面板character sheet
角色参考图**必须**使用4面板2x2 grid格式，不是单张环境立绘。

**4面板布局**：
- 上排左：FACE FRONT（正面脸）
- 上排右：FACE SIDE（侧面脸）
- 下排左：BODY FRONT (NO FACE)（正面身·刻意无脸）
- 下排右：BACK（背面身）

**棚拍规则**：
- 纯色冷灰棚拍背景（#606570）
- 单一侧逆光45度，无填充光，冷钢蓝色调
- 底左panel刻意无脸（方便后续编辑）
- 面板标签 + 标题

### 场景参考图
常规场景使用9宫格展示多角度/多时段。**室内场景优先遵循下方「室内场景参考图」专节，不强制9宫格。** 室内连续戏的制作参考保持同一时段；时间与光线探索稿单独标记，不混作连续性参考。

## 室内场景参考图（Indoor scenes）

本节仅用于室内场景。目标是让房间支持剧本动作，并让所需镜头共享可信的空间关系。角色棚拍格式和室外场景流程不因本节改变。简单室内空镜可直接使用一张主视图；有走位或人—物交互时，再补充相应检查与素材。

### 1. 先定动作与使用关系，再布置装饰

- 从剧本提取必要动作、关键家具/道具及其状态；用简短的房间用途、主人身份与生活习惯决定可见陈设。
- 对关键交互写清：物体的使用侧、人物站位与朝向、手部接触点、进入路径、开启方向及所需净空。区分**物体正面、房间方位、摄影机一侧**；不要只写「桌旁」或用画面左右代替所有角度的空间坐标。
- 先让家具可用，再选择能看清动作的机位。例如抽屉朝使用者开启，椅子与桌子的工作侧关系合理；不能只为了让摄影机看见抽屉，把人物安排在必须跨越桌面才能够到的位置。
- 空间关系复杂时，先用简易俯视图或粗略blockout标出家具朝向、人物落点、开启范围和机位。尺寸是设计假设；生成图不能当作已验证的施工尺寸。简单空镜不强制平面图。

### 2. 先建立一张可用主视图

按目标镜头画幅生成单张、足够清晰的房间主视图。检查家具结构、通路、接触位置、视线和光源后，选定它作为布局依据；空间不成立时先修布局，再补装饰。

制作素材保持同一套家具、道具位置、开启状态和时段。若剧情要求状态变化，分别标明动作前后状态。规划图上的箭头、文字和人物标记与干净制作图分开，避免被误当成成片元素。

### 3. 按分镜派生所需视图，不凑九张

- 从选定主视图和已有细节图派生所需角度；能用裁切得到的镜头不必重新设计房间。新角度暴露未知结构时，重新检查几何关系。
- 按用途提供主视图、关键道具细节、必要的对白角度等；数量由分镜决定。保留符合目标画幅的独立高分辨率图，不让小格图成为关键结构的唯一依据。
- 九宫格可作为选定视图的审阅总览；不要求一次生成九个彼此独立的房间版本。引用同一主图也不能保证派生图自动共享精确三维结构，仍须对照检查。

### 4. 用摆位帧验证难交互

空房间图定义环境，不能证明人物如何使用物体。遇到够取、开合、坐下等容易误解的动作，用实际角色参考补充一张关键摆位/接触帧，明确身体位于哪一侧、手接触哪里、视线是否可达。

摆位帧不套用角色棚拍的2×2格式，也不以抽象心理姿态替代物理位置；它补充干净场景图与角色身份图。仅写提示词时可交付该帧的提示词和待生成状态，不把未生成素材列为现有图片。

### 5. 检查结果并交接视频阶段

仅检查当前动作涉及的项目：

- [ ] 人物能否到达使用侧，家具是否挡路或挡住必要视线？
- [ ] 手能否到达接触点，而不穿越桌面、墙面或其他实体？
- [ ] 抽屉/门等开启范围是否与人物、椅子、墙壁冲突？
- [ ] 全景与细节是否为同一结构、比例关系、道具位置及开合状态？
- [ ] 相邻镜头的人物位置、朝向、视线与光源是否能连续？
- [ ] 返回同一全景时是否有明确的主机位依据，而非任意替换另一角度？

「完全相同」「严格保持」是提示意图，不是验证结果。根据生成图的可见证据说明哪些已成立、哪些仍有疑问；未通过交互检查的图保留为设计探索，不宣称已可直接用于拍摄。

交接时为每张实际图片指定用途：角色身份、环境布局、道具结构、人物接触姿态或镜头起始状态。说明冲突时哪个素材控制哪个属性，不让整张多视图表同时决定所有镜头。区分构图参考与平台专用首帧输入；需要精确首帧时核对目标平台的输入模式。

## 参考图4原则（场景参考图）

1. **色卡融入叙述** — 色号不单独列出，融入描述性段落中。如"石墙#B5B0A8"写成"灰褐色石墙"
2. **PHOTO TONE一段压完** — 照片色调/光线/氛围在一段内完整描述，不分散
3. **AVOID精简+场景特定** — NOT清单每条针对本场景可能出现的具体错误，不堆通用否定词。按类别分组
4. **MATERIAL TRUTH** — 材质真实描述，写明每种材质的物理特性（粗糙/光滑/湿润/风化等）

## 9宫格4原则（场景参考图）

1. **panel视觉钩子** — 每个panel用1-2句话锚定视觉重点
2. **色卡统一PRESERVE** — 9个panel色调统一，不出现色温跳变
3. **贯穿核心概念** — 9个panel围绕同一场景的核心特征展开
4. **绝对语言** — 用绝对肯定的描述语言，不用"可能""大约""似乎"

## 角色参考图写法要点

### 影视参考锚定法
引用电影/游戏给模型文化视觉锚点。如"The Road (2009) / Snowpiercer (2013) / Medieval peasant levy"。帮助模型理解整体美学方向。

### NOT清单分类组织法
否定指令按类别分组：
- FACE: no beard mismatch, no scar on wrong side
- BODY: no modern clothing, no clean fabric
- LIGHT: no fill light, no warm tone
- FORMAT: no environment background, no single portrait

### 姿势=心理状态写法
不写物理位置描述（"手放在腰间"），写角色能量和心理状态（"重心后脚，随意权威的姿态"）。每个panel的姿势反映角色性格。

### 标志性装备=角色身份
为角色设计DNA物件——一眼能认出是谁的标志性装备。在参考图中明确锚定。

### 角色差异化设计方法
同一阵营的多个角色必须有明确的视觉区分：
- 体形差异（矮壮vs瘦高）
- 面部特征差异（疤痕位置/胡须密度/鼻型）
- 护甲差异（材质来源/覆盖范围）
- 武器差异（类型/尺寸/材质）
- 标识物差异（同一标识但佩戴方式不同——如灰布条缠不同手臂、缠绕方式不同）
- 姿态差异（重心/手持武器方式/跟随者vs领头者气质）
- 参考美学差异（引用不同的影视参考）

## 色卡规则

- 参考图提示词中保留色号（如#4A4540）
- CLIP提示词中取消色号，改用描述性语言
- 跨文件色卡一致性验证：同一角色/场景在参考图和CLIP中的色卡描述必须一致
- 冷色调场景：100%冷色零暖色
- 暖色调场景：暖光主调但需有冷色平衡

## 质检清单

- [ ] 角色参考图是否为4面板character sheet格式？（不是单张立绘！）
- [ ] 4面板布局是否正确？（正面脸/侧面脸/正面身无脸/背面身）
- [ ] 棚拍背景是否为纯色冷灰？
- [ ] 是否单一侧逆光45度无填充光？
- [ ] 底左panel是否刻意无脸？
- [ ] 同一阵营多角色是否有明确视觉区分？
- [ ] 色卡是否融入叙述而非单独列出？
- [ ] AVOID清单是否场景特定？
- [ ] 影视参考是否标注？
- [ ] 面板标签和标题是否完整？
